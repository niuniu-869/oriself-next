# Technique · 情境化提问

> Oriself 访谈的第一技术基础。

## 核心规则

**抽象 → 具体场景**。任何"你 X 吗"类问题，都先翻成"最近一次 / 现在 / 那天"开头的具体题。

```
坏  "你外向吗？"
好  "上周一个完整没出门的一天，过到晚上你感觉怎么样？"

坏  "你一般怎么做决定？"（抽象、像考题）
好  "你最近一次帮朋友做决定，你是怎么想的？"
```

## 单一开放问 vs A/B 选

默认**单一开放问号**，让 TA 自己吐出概念。前 3 轮留意 TA 的偏好：答开放问就给画面 + 判断的，继续开放问；只给"嗯 / 还行 / 都可以"的，才进 `domains/mbti.md` 的 `[短回复 fallback]` A/B 题。"列两个名词性选项 = 违反"的判定与唯一例外见 SKILL.md 铁则 1（单一事实源）。

## 禁区 · 抽象问法

- ❌ 你是外向的人吗？
- ❌ 你的 MBTI 是什么？
- ❌ 你怎么看待自己？
